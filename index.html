Why it's fast.

  1. System libraries run as PC code.

    Android's C and math calls execute natively, not as translated ARM.

  2. Java runs on a desktop JVM.

    Game Java is compiled by HotSpot's optimizing JIT.

  3. Frames go straight to your headset.

    Eyes reach OpenXR from inside the game's own process.

Why it just works.

  1. OpenGL ES through ANGLE.

    GLES games render on your PC GPU, just like Vulkan ones.

  2. VrApi games run unpatched.

    Older Oculus SDK titles run on your OpenXR runtime.

  3. 32-bit games run on Venture.

    32-bit ARM titles run right alongside 64-bit ones with their own JIT.

  4. Apps start like they do on a Quest.

    Launch activities resolve the way Android does, so games start as-is.
