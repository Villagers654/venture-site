What's new in Venture 0.2.0

Venture 0.2.0 is our biggest update since launch. Games stutter far less, every controller can be remapped, resolution and frame rate can be set per game, and mixed reality works on many more setups.

Less stutter

Venture translates each game's ARM code and its phone shaders while you play. Until now that happened the moment a game needed something new, which showed up as hitches, and it started over on every launch.

0.2.0 saves translated code and loads it on the next launch. Spare CPU cores translate the code a game is about to reach, and shaders are compiled in the background before the game asks for them.

Here is 0.2.0 against 0.1.0 on our Windows test PC, on the same route in each game.

Controls

The new Controls page shows the controller you actually own, drawn from the 3D model SteamVR has installed, with a line from each Quest button to the button it uses. Pick a binding and its line lights up. Drag a controller to turn it and see the buttons on the other side.

The menu button can be any single button, a held button or two buttons pressed together. Defaults are tuned for Index, Vive, Touch, PSVR2 Sense, Steam Frame, Windows Mixed Reality, Pico 4, Focus 3 and more, and any game can have its own controls on its Controls tab.

Resolution and frame rate

Games still run at the resolution and refresh rate your runtime picks. If you want something else, you can now set both in Settings for every game, or for one game on its own Settings tab.

Mixed reality on more setups

Venture asks your runtime what it can do and uses the best passthrough it offers. That covers Meta's passthrough over Quest Link and Air Link, SteamVR headsets with cameras (directly or through Rectus's OpenXR SteamVR Passthrough layer), the Steam Frame through McFredward's steam-link-native-passthrough, and Monado and WiVRn on Linux. Streaming apps with colour keying, like Virtual Desktop, ALVR and steam-frame-chroma-key, work with the Color key setting.

The wiki has a setup guide for each.

Elsewhere, you can install an older version of a game next to the current one, and the library now has search. Everything else is in the full release notes.
