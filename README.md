# Venture website

The website for [Venture](https://github.com/Villagers654/Venture).

## Run it

```sh
python -m http.server 8765
```

Then open http://localhost:8765.

## Files

| File | What it holds |
|---|---|
| `index.html` | Page structure and all copy |
| `style.css` | Styles. Colours are the launcher's tokens at the top |
| `data.js` | Benchmark and compatibility numbers behind the chart and game grid |
| `app.js` | Renders the chart and grid, and points the download buttons at the latest release |
| `blog.css` | Styles for the News page and posts, on top of `style.css` |
| `blog/posts.json` | The posts, newest first: slug, title, date, summary, images |
| `blog/<slug>/` | One post: `index.html`, its `media/`, and any chart data |
| `blog/feed.xml` | RSS feed, generated by `tools/build_blog.py` |
| `assets/` | Logo, hero image, share image and game art (`games/<id>.jpg`, 640×360) |

To add a game, put its art in `assets/games/` and add a `[name, art id, fps, [other runtimes]]` row to `games` in `data.js`.


## Blog

A post is a folder `blog/<slug>/` with its `index.html` (copy the newest post's page for the nav, footer and head)
and a 1200×630 `media/og.jpg`, plus one entry at the top of `blog/posts.json`. Then run

```sh
python tools/build_blog.py
```

which writes the post list on `blog/index.html`, each post's date line and `blog/feed.xml`. Commit all three.
A post with `"date": null` shows a marked "Release date" placeholder and has no date in the feed; set the date
when it is published. The 0.2.0 post's chart numbers live in `blog/0-2-0/data.js` (`null` = not measured yet).
